#### The following enhancements have been made to the `ManageEngine Log360` Connector in version 2.0.0:

- Re-developed the connector using the v2 REST APIs, replacing the deprecated v1 APIs.
- Updated all the existing actions to align with the v2 APIs.
- Added the following new actions and playbooks:
    - Get Incidents List
    - Get Incident Details
    - Execute an API Request
- Updated the output schema for all the actions.
